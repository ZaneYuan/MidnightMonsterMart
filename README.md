# Midnight Monster Mart

A Unity game project.

## Requirements

- Unity (see `ProjectSettings/ProjectVersion.txt` for the exact editor version)
- [Git LFS](https://git-lfs.com/) — binary assets (textures, audio, models) are stored via LFS

## Getting started

```bash
git lfs install
git clone <repo-url>
```

Then open the project folder in Unity Hub.

## Repository layout

Unity-generated folders (`Library/`, `Temp/`, `Build/`, `Logs/`, `UserSettings/`) are
not tracked — see `.gitignore`. Binary asset types tracked through Git LFS are listed
in `.gitattributes`.
